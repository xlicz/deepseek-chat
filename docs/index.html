DeepSeek Chat for Android

把 DeepSeek 官方开源的网页版界面 chat-demo 打包成安卓 APK。界面是官方的开源实现，功能完整，直接调用 DeepSeek API —— 没有自建后端，没有中转服务器。

下载 APK 查看源码

最新版本 v0.1.0 · 约 4.9 MB · Android 7.0+ · 需要自备 DeepSeek API Key

它解决什么问题

官方网页版功能齐全，但在手机上要用浏览器打开，或者「添加到主屏幕」。这个 App 把它做成真正的应用：桌面有独立图标，返回键按层级返回，导出的文件和附件能用系统对话框保存与打开。适合想用一个独立入口、又希望数据完全留在本机的安卓用户。

安装

  1. 打开 Releases，下载最新版 deepseek-chat-<版本>.apk。
  2. 在手机上点开文件。提示「未知来源」或「不允许安装未知应用」时，允许当前浏览器或文件管理器安装。
  3. 打开 App，在设置里填入 DeepSeek API Key，开始对话。

安装包没有上架任何应用商店。下载后建议核对 SHA-256，每个 Release 的正文里都写了对应值。

常见问题

这是 DeepSeek 官方发布的 App 吗？

不是。这是第三方打包的社区项目，只复用官方开源的 chat-demo 网页界面。官方渠道只有应用商店里的 DeepSeek App 和 chat.deepseek.com。

用这个 App 需要付费吗？

App 本身免费开源。对话走 DeepSeek API，按官方价格从你自己的账户扣费，需要先在 platform.deepseek.com 申请 API Key 并充值。

支持哪些安卓版本？

Android 7.0（API 24）及以上，且系统 WebView 版本不低于 105。旧机型 WebView 偏低时，可以在应用商店更新「Android System WebView」。

和官方 App 比少了什么？

没有官方账号体系、没有官方 App 特有的多模态功能，不能自动更新。数据都留在本机，换机要自己导出导入。

APK 安全吗？怎么验证？

源码在 GitHub 公开，可以自行构建比对。每个 Release 都给出安装包的 SHA-256 和签名证书 SHA-256，发布后没有再改包；签名用固定的正式密钥，后续版本可覆盖安装。

安装时被 Play Protect 拦截怎么办？

手动安装、未上架商店的小体积包常被拦。确认来源是本仓库 Releases 后可以继续；若系统只给「取消」，可临时关闭 Play 保护机制校验，装完再打开。

支持 iOS 或鸿蒙吗？

不支持。仓库只有 Android 工程。iPhone 可以把网页版添加到主屏幕，鸿蒙 NEXT 不在支持范围内。

会收集或上传我的数据吗？

App 没有埋点、没有第三方统计，只有 DeepSeek API 一个网络出口。API Key 和会话存在本机 WebView 存储里，系统备份已关闭（allowBackup=false），卸载会清空数据。

自己构建

需要 Node.js 22.12+、pnpm、JDK 21 和 Android SDK（platform 36 / build-tools 36）。

git clone --recurse-submodules https://github.com/xlicz/deepseek-chat.git
cd deepseek-chat
pnpm install
export JAVA_HOME=<JDK 21 路径>
export ANDROID_HOME=<Android SDK 路径>
pnpm apk:debug

产物在 android/app/build/outputs/apk/debug/app-debug.apk。完整说明见仓库 README。
